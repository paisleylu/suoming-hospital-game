# 索命诡院 · 引擎开发与机制扩展技能 (Suoming Engine Skill)

本技能提供《索命诡院》的核心 3D 架构逻辑、场景坐标系统、NPC 实体行为及解谜玩法拓展指导。

---

## 1. 场景与坐标系统规约

* **坐标轴定义**：
  * **X 轴**：走廊横向。走廊主干道宽度为 `-4.5` 到 `+4.5`，左右两侧为病房区域（负方向为西侧病房，正方向为东侧病房）。
  * **Y 轴**：垂直高度。玩家眼睛视线高度约为 `1.60`，地面高度在 `0` 附近，天花板高度为 `3.5`。
  * **Z 轴**：纵向进深。走廊入口为 `Z = 3`，最深处终点为 `Z = -32`。
* **碰撞边界 (`walkable`)**：
  碰撞检测采用 2D AABB 盒列表 `walkable = [{x1, x2, z1, z2}, ...]`。
  当添加新房间或解锁房门时，必须向 `walkable` 动态压入通道通行区域。

## 2. 核心游戏机制设计与代码接入

### 2.1 抱起与抛投机制（E 抱起 / Q 抛投）
- **捡起判定**：靠近地面的掉落物（如人头或病患）按 `E`，将其挂载到玩家摄像机前方。
- **抛出判定**：按 `Q` 给物体一个沿摄像机朝向的向前初速度；
  如果物体命中了正在追逐的怨灵（`Math.hypot(obj.x - ghost.x, obj.z - ghost.z) < 1.2`），怨灵触发硬直倒地 2 秒。

### 2.2 病床伪装与心率博弈（H 躲藏 / 空格稳心率）
- **触发条件**：在病房靠近病床按 `H`，角色平躺伪装。
- **心率博弈**：怨灵靠近时，玩家心率会飙升；玩家必须跟随心电节拍按“空格键”进行平息。一旦心率超过警戒值，怨灵会直接掀开被子判定搜寻成功。

## 3. 难度模式矩阵

1. **peaceful (安心探索)**：追逐者完全不触发攻击，仅作为静态氛围展览，适合低龄小朋友或纯剧情探索。
2. **easy / normal (简单 / 普通)**：标准追逐速度，药房与档案室密码带有明显的发光线索。
3. **hard / ultimate (噩梦 / 极限噩梦)**：双翼迷宫完全开放，追逐速度提升 25%，允许失误次数上限为 3 次。
4. **inspection (1998 夜班巡检)**：独立诊断玩法。玩家扮演值班医生巡查 8 间病房，根据病房异常现象在门牌上挂牌诊断，正确封锁所有异象后通关。
